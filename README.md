# Theo Trading Bot

Bot de trading automat, personal: acțiuni SUA, daily, long-only, paper întâi. Regulile complete: `AGENTS.md`.

## Pornire (o singură dată)

1. Terminal: `cd ~/theo-trading-bot && bash scripts/set_keys.sh` → lipești cheile Alpaca (restul: Enter, le pui mai târziu).
2. Deschizi folderul `theo-trading-bot` în Antigravity și scrii: **preia**.
3. Când agentul îți spune, deschizi o conversație nouă și scrii din nou **preia**.

## Cuvinte-cheie pentru agenți

- **preia** — continuă de unde a rămas proiectul.
- **predare** (sau **limită**) — salvează tot pe GitHub, ca alt agent să poată continua.
- **review etapa X** — verifică munca unei etape.

Cine face fiecare etapă (Antigravity sau Claude Code): tabelul „Cine face ce” din `AGENTS.md`.
